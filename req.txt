Scanned QR data to be sent to a ESP32.
Entities:
    Clients - organisations subscribing for services
    Users -  Belong to Clients. 
    Settings - Belong to Clients. Can be edited only by its own Client Users

User Workflows:
1. Authentication

2. Users need to scan QR and send QR information to ESP32(Maybe an API call)
    if QR has shelf code send to ESP32
    else Get shelf code from 3rd Party application(Maybe an API call). AND send shelf code send to ESP32
3. Settings page for field mapping and LED glow time
    if 3rParty application shelf code is different from our shelf code, use mapping table.
